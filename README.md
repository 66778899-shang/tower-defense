# 塔防指挥官 · Tower Defense Commander

> 仓库地址：https://github.com/66778899-shang/tower-defense · 许可证：MIT

一个**零依赖的单文件 HTML5 塔防游戏**：一个 `index.html`（约 100KB，内联全部 CSS/JS + Canvas 渲染），双击即可运行，不需要构建、不需要 npm install、不需要联网。

```
git clone https://github.com/66778899-shang/tower-defense.git
cd tower-defense
# 直接双击 index.html，或者：
python -m http.server 8000     # 然后打开 http://127.0.0.1:8000
```

---

## 玩法

- **双入口双路径**：敌人从两个入口分两路推进，最后汇入同一个基地。只守一侧必输。
- **4 种塔**：箭塔（单体高频） / 炮塔（范围溅射，**无法对空**） / 冰霜塔（减速控场） / 激光塔（穿透光束，自带破甲）
- **升级与专精**：每座塔可升到 Lv3，之后二选一专精到 Lv4（如箭塔 → 连弩 / 狙击）
- **战术技能**：空袭（选点范围伤害）与极寒冻结（全场减速），各有冷却
- **5 个关卡**：从 12 波的教学关到 24 波的熔岩要塞，外加一个无尽模式；通关评星，拿星解锁下一关
- **地图编辑器**：拖动拐点自定义双路径，可保存到本地或导出为配置代码
- **本地记录**：最佳波次、总击杀、成就徽章、无尽最高纪录，存在 localStorage

## 建模设计（这个项目的重点）

游戏没有采用"拍脑袋写死数值"的做法，而是搭了几层可解释的建模，改任何一处配置都不会悄悄破坏曲线。

### 1. 敌人属性管线

```
实际数值 = 基础值 × 关卡曲线^波次 × (1 + 波次 × 速度曲线) × 词缀修正
```

所有敌人都走 `spawnEnemy()` 这一个出口，改数值只动 `LEVELS` 配置表。

### 2. 伤害类型 × 抗性矩阵

伤害分 **物理 / 火焰 / 冰霜 / 能量** 四类，每种塔有固定的伤害类型；敌人各有抗性与弱点（负数抗性 = 易伤），关卡还会给全军附加抗性加成：

| 关卡 | 全局抗性 | 意味着 |
|---|---|---|
| 霜寒隘口 | 冰霜 +30% | 只堆冰霜塔会吃大亏 |
| 熔岩要塞 | 火焰 +35% | 灼烧不再是万金油 |
| 终末防线 | 火焰 +20% / 冰霜 +20% | 需要混搭 |

抗性是**相加**的：疾行者自带火弱 30%，进了熔岩要塞变成 +5%，弱点被地形抵消。

伤害结算顺序：**抗性 → 护盾吸收 → 破盾易伤(+25%) → 护甲**。

### 3. 威胁值

`enemyThreat(血, 速, 甲, 机制)` 把所有敌人折算成一个可比的数：

| 小兵 | 疾行者 | 飞行兵 | 治疗师 | 护盾兵 | 重甲兵 | 首领 |
|---|---|---|---|---|---|---|
| 0.9 | 1.0 | 1.9 | 4.2 | 5.7 | 5.8 | 49.6 |

威胁值有两个用途：

- **波次预算**：每波给一个强度预算 `power0 × powerCurve^(波次-1)`，再从敌人池里按权重采购，直到预算用完。加新敌人不用重新推导曲线。
- **塔的目标策略**：可切换"打最前面的 / 打威胁最高的"，治疗师与首领因此会被优先集火。

### 4. 塔的建模

- **每塔一套成长曲线**（不再是四种塔共用一套系数）：

  | 塔 | 升级涨什么 |
  |---|---|
  | 箭塔 | 攻速 1.17、伤害 1.56 —— 靠频次，后期怕护甲 |
  | 炮塔 | 伤害 1.72、溅射 1.12 —— 一发清一片 |
  | 冰霜塔 | 减速 1.10、射程 1.13、伤害 1.42 —— 靠控场 |
  | 激光塔 | 射程 1.15、伤害 1.68、破甲 1.10 —— 靠覆盖与穿透 |

- **综合战力** `powerOf = DPS × 控场 × 溅射 × 破甲`，Lv1：箭塔 16 / 炮塔 32 / 冰霜 10 / 激光 28
- **升级按增益定价**：`造价 × 0.25 × 等级 × 战力增益²` —— 涨得慢的塔升级更便宜（冰霜 52 金，激光 135 金）
- **冰霜塔优先给未减速的敌人上 debuff**，避免重复减速浪费

### 5. 敌人机制

- **护盾兵**：护盾 = 最大生命 70%，护盾期间免疫减速，破盾后受伤 +25%
- **治疗师**：每 2.5 秒治疗半径 96 内友军（不超上限）—— 不优先点掉就永远打不死前排
- **飞行兵**：无视路径直扑基地（路程只有地面的 40%），且炮塔打不到
- **词缀**：铁甲 / 疾风 / 巨化，从第 N 波起随机附加

## 主题化背景

每关一套地形：地面配色、装饰物（草丛 / 水洼 / 雪堆 / 岩浆裂缝 / 废墟）与氛围粒子（落叶 / 薄雾 / 飘雪 / 火星 / 灰烬）。

地形烘焙到离屏 canvas，只在换关或改地图时重建，每帧只贴一次图；装饰用确定性伪随机生成，不会每帧抖动。

## 开发

```bash
node _smoke.js
```

在 node 里 stub 掉 DOM/Canvas 后直接 eval HTML 里的脚本，跑真实游戏逻辑。**194 项断言**，覆盖：

- 地图连通性、路径逐格连续、双路径汇入同一基地
- 伤害公式、抗性矩阵、护盾与治疗机制
- 波次预算是否真的约束住强度、强度是否单调递增
- 塔的成长曲线、战力度量、升级定价与出售价是否自洽
- 五套地形与全部 UI 面板的渲染无异常
- **AI 自动对局**：笨 AI 每关跑 3 个种子取平均，验证难度曲线单调

输出示例：

```
[复测] 每关跑 3 个种子取平均
    边境哨站  平均到达 W15.0  平均剩血 18.7/20  塔 45
    双叉河谷  平均到达 W15.0  平均剩血 11.3/20  塔 45
    霜寒隘口  平均到达 W13.0  平均剩血 0.0/20  塔 36
    熔岩要塞  平均到达 W11.3  平均剩血 0.0/18  塔 25

```
